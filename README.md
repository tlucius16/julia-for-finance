# Quant finance in Julia

A hands-on walk through core quantitative finance topics in Julia, using real market data. It covers risk (VaR, expected shortfall, volatility models), portfolio optimisation, options, a small machine-learning experiment, and macro data from FRED.

Each chapter is a single script that downloads its own data, explains each step in comments, and ends with a **Takeaways** block summarising what the data showed. The examples use eight US bond ETFs, but you can change the tickers in one place.

This is learning material, so the code favours readability over speed or completeness. For a one-page summary of the formulas and code, see the [cheat sheet](CHEATSHEET.md).

## Chapters

| File | Topic | Covers |
| --- | --- | --- |
| [01_data.jl](01_data.jl) | Data | Downloading prices, normalised and log-scale plots, the returns matrix, and estimating duration from the 10-year yield |
| [02_var_es.jl](02_var_es.jl) | VaR and expected shortfall | Historical, Normal and Monte Carlo (Normal and Student-t) methods, portfolio VaR and diversification, the Kupiec backtest |
| [03_volatility_models.jl](03_volatility_models.jl) | Volatility | EWMA, GARCH(1,1) by maximum likelihood, filtered historical simulation, the Christoffersen backtest |
| [04_portfolio_optimization.jl](04_portfolio_optimization.jl) | Portfolios | Efficient frontier, max Sharpe, min ES (linear program), weight caps, Ledoit–Wolf shrinkage, risk parity, out-of-sample tests |
| [05_option_data.jl](05_option_data.jl) | Options data | Cleaning an option chain, implied spot from put–call parity, the volatility smile, open interest |
| [06_machine_learning.jl](06_machine_learning.jl) | Machine learning | Momentum and risk features, PCA, cross-sectional ridge regression, rank IC, a rotation backtest, and how to avoid look-ahead |
| [07_option_pricing.jl](07_option_pricing.jl) | Option pricing | Black–Scholes, Greeks checked by finite differences, implied vol by Newton's method, Monte Carlo pricing |
| [08_economics.jl](08_economics.jl) | Economics | FRED data: rates, the yield curve and recessions, inflation and the Fed, a rates-plus-credit model of the ETFs |

Shared settings and helper functions are in [common.jl](common.jl). The chapters build on each other loosely. Chapter 06 reads the risk features that chapter 03 exports, and chapter 07 reads the option chain that chapter 05 downloads. Running them in order is safest.

## Setup

1. Install [Julia](https://julialang.org/downloads/). The code was written on Julia 1.12.
2. Install the packages once:

   ```bash
   julia setup.jl
   ```

3. Run a chapter. The best way is to open it in VS Code with the [Julia extension](https://www.julia-vscode.org/) and run it cell by cell: cells are separated by `##`, and shift+enter runs one. Each cell's last plot or table appears in the plot pane or REPL.

   You can also run a whole file from the terminal, but the plots won't appear:

   ```bash
   julia 01_data.jl
   ```

No API keys are needed. Prices and option chains come from Yahoo Finance via [YFinance.jl](https://github.com/eohne/YFinance.jl), and economic data comes from [FRED](https://fred.stlouisfed.org/)'s public CSV downloads.

## Data and caching

Downloads are cached as CSV files in `data/`, which is not committed: every file in it is regenerated by running the chapters. Each `load_*` function reads its cached file if one exists. To download fresh data, pass `refresh = true`, or delete the file.

To use different assets or dates, edit `TICKERS`, `START` and `STOP` in [common.jl](common.jl), then refresh the cached files.

- **Option chains are a snapshot.** `options.csv` records the moment it was downloaded in its `asof` column, so refresh it to see today's market.
- **The takeaways describe the data when they were written** (to October 2026). Your numbers will differ if you refresh.

## Notes

- [archive/yahoo_finance_original.jl](archive/yahoo_finance_original.jl) is the original single-file exploration that the chapters grew out of. It's kept for reference and isn't maintained.
- **`UndefVarError` with an "ambiguity" hint, or a `MethodError` right after installing a package:** restart the Julia REPL. The session may still have an old package version loaded, or two loaded packages may export the same name.
